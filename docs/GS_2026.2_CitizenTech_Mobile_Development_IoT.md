# GS 2026.2 --- CitizenTech

## Mobile Development & IoT

## Conceito da atividade

Toda CitizenTech precisa chegar à mão do cidadão, e na maioria das vezes
ela chega pelo celular. Nesta Global Solution, a disciplina de Mobile
Development & IoT fica responsável pela interface e pela experiência da
solução da equipe. É no app que o morador registra um buraco, o idoso
recebe o alerta de calor ou o passageiro consulta a lotação do trem.

Os dados podem vir de uma API pública ou de dados simulados (mock).
Backend externo, ausente ou incompleto não reduz a nota desta
disciplina. O foco aqui é o front-end.

## Objetivo

Demonstrar, em um app React Native funcional, que a equipe sabe:

1.  **Estruturar um app real.** O app usa TypeScript, navegação com Expo
    Router, componentes reutilizáveis e um tema centralizado.
2.  **Consumir dados.** Os dados vêm de uma API pública ou de um mock, e
    o app trata os estados de carregamento, erro e lista vazia. A equipe
    escolhe a forma de fazer as requisições, por exemplo `fetch` ou
    Axios.
3.  **Persistir informações.** O app salva e recupera dados em um banco
    de dados, local ou em nuvem. A equipe escolhe a opção que fizer mais
    sentido para a solução, por exemplo SQLite, Supabase ou Firebase.
4.  **Atender o cidadão real.** O app tem letras legíveis, bom
    contraste, linguagem simples e suporte a leitor de tela.

## Requisitos mínimos do app

-   Pelo menos **3 telas** ligadas à jornada principal do cidadão, como
    início, registro ou consulta, e detalhe ou histórico.
-   Projeto **Expo + TypeScript**, rodando no Expo Go ou no emulador.
-   Navegação com **Expo Router**.
-   Consumo de dados de uma API ou mock, tratando **loading, erro e
    lista vazia**.
-   Banco de dados, local ou em nuvem, para salvar e recuperar pelo
    menos uma informação da jornada do cidadão.
-   Cores, fontes e espaçamentos centralizados em um arquivo de tema,
    nunca fixos direto no código.
-   Nada de dados pessoais reais. Usem dados simulados ou públicos e
    informem a fonte no README.
-   Apenas ferramentas e serviços gratuitos, incluindo planos gratuitos
    de bancos em nuvem.

## Entregáveis

A entrega é o repositório no GitHub da equipe, que deve conter:

1.  O código-fonte completo do app.
2.  O README com:
    -   A Ficha da CitizenTech no topo.
    -   Nome e RM dos integrantes.
    -   As instruções para rodar o app (`npx expo start`).
    -   O banco de dados escolhido e o motivo da escolha.
    -   A explicação de onde vêm os dados.
    -   Prints das telas principais.
    -   O link do vídeo de até **3 minutos** (YouTube, não listado)
        mostrando o app rodando, a jornada principal completa e os dados
        sendo salvos e recuperados.

Deixem o repositório público ou deem acesso ao professor antes do prazo.
Não publiquem chaves ou senhas de banco em nuvem no repositório: usem um
arquivo `.env` listado no `.gitignore` e expliquem no README como
configurá-lo.
